ORGANIZER 2.8 - START HERE
==========================

1_Project           all program files. Unzip the whole folder somewhere permanent (e.g. D:\Organizer_2.8),
                    open 1_Project and double-click app.bat (the window) - or install.bat, then doctor.bat, for the background task.
2_History           what changed in each version (CHANGELOG), every test we ran with results
                    (TEST_RESULTS), and the full project summary.
3_Possible_Updates  what we can add or fix next (UPDATES_PLAN, TODO).

If the window does not open, double-click 1_Project\selftest.bat - it says what is wrong and how to fix it.

Do not move 1_Project after running install.bat (the scheduled task remembers its location).
